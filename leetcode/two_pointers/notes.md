# 双指针 · 章节笔记

> 对应题目：167 两数之和 II · 11 盛最多水的容器 · 15 三数之和 · 18 四数之和
>
> 更新时间：2026-09-30

---

## 一、核心思想

**利用"有序性 / 单调性"，让"该移动哪个指针"这个决策有依据 —— 从而一次扫描排除大片不可能的解。**

- 数组**有序** → 和大了就右指针左移、和小了就左指针右移（167）
- 面积由**短板**决定 → 只能移动短板（11）
- 固定 k 个元素后，剩下的变成"两数之和"（15/18）

## 二、识别信号

| 看到题面出现 | 该想到 |
|---|---|
| "**已排序**的数组"、"按非递减顺序" | **对撞双指针** |
| "两数/三数/四数之和 = target" | 排序 + 双指针（或哈希） |
| "最大面积/容量"，且**只有两端参与** | 对撞双指针 + 贪心移动 |
| **空间复杂度要求 O(1)**（如 167） | **不能用哈希表** → 双指针 |
| "不能重复使用同一个元素" | `left < right` 天然保证 |

## 三、两个模板

**① 对撞双指针（167 / 11）**
```python
left, right = 0, n - 1
while left < right:
    ...                    # 计算当前值
    if 该移动 left:
        left += 1
    else:
        right -= 1
```

**② 排序 + 固定 k 个 + 双指针（15 / 18）**
```python
nums.sort()
for i in ...:                     # 固定第 1 个
    if i 与前一个重复: continue
    for j in ...:                 # 固定第 2 个（18 才有）
        if j 与前一个重复: continue
        left, right = j + 1, n - 1     # 双指针在循环内部重置！
        while left < right: ...
```

> **复杂度规律**：求 `k` 个数之和，就是"固定 `k-2` 个 + 双指针"，总复杂度 $O(n^{k-1})$。
> 三数之和 $O(n^2)$、四数之和 $O(n^3)$。

## 四、去重三招（15 / 18 的关键）

```python
# ① 外层去重：向后看（注意 > 0 的边界，避免越界）
if i > 0 and nums[i] == nums[i - 1]:
    continue

# ② 找到解后：跳过相邻重复
while left < right and nums[left] == nums[left + 1]:
    left += 1
while left < right and nums[right] == nums[right - 1]:
    right -= 1

# ③ 找到解后左右同时移动（只动一边必然还是重复）
left += 1
right -= 1
```

> **"向后看"而不是"向前看"** 的原因：`i` 从左往右遍历，向前看（`nums[i+1]`）可能越界，所以用 `nums[i-1]` 并配合 `i > 0`。

## 五、我踩过的坑（重点回顾）

| 题目 | 踩的坑 | 教训 |
|---|---|---|
| **11** | 想加一条"两边等高时，比较 `height[left+1]` 和 `height[right-1]` 决定移动谁"的规则 | **冗余！** 等高时两边都是短板，移动谁都会被对面的短板限制住 → **删掉**。贪心规则要能说清"为什么不留最优解" |
| **15** | 担心 `result.append([...])` 里的列表被后续修改 | ⚠️ `.append()` 存的是**引用**。如果用 `tmp = [a,b,c]` 再 append，之后 `tmp = [...]`（重新赋值）**不会**影响已存的内容；但如果 `tmp.append()`（原地改）就会污染。**最稳的写法：直接 append 字面量** |
| **15/18** | 跳重复时可能越过边界 | `while left < right and ...` **必须带上 `left < right`** |
| **167** | 题目要求**下标从 1 开始** | 返回时要 `left + 1, right + 1`（Python 内部下标仍从 0 起） |
| **18** | 两层固定的去重判断不对称 | 内层用 `index2 > index1 + 1`，且与**前一个已处理**的位置比较 |

## 六、为什么双指针是对的（面试要能说）

**11 盛最多水的容器**：

> 面积 = `min(左壁, 右壁) × 底边`。每移动一次，**底边必然缩小**。
> 所以想让面积变大，**只能指望短板变长** → 那就移动短板。
> 移动长板的话，短板没变、底边还缩小了，一定不会更优 → **不可能丢掉最优解**。

**167 两数之和 II**：

> 有序数组里，`left` 指向最小、`right` 指向最大。
> 和太小 → 只有增大 `left` 才可能追上；和太大 → 只有减小 `right`。
> 每次都能**确定地排除掉一整行（或一整列）** 的组合。

## 七、复杂度速查

| 题 | 时间 | 空间 | 关键手法 |
|---|---|---|---|
| 11 盛最多水的容器 | $O(n)$ | $O(1)$ | 对撞双指针 + 移动短板 |
| 15 三数之和 | $O(n^2)$ | $O(1)$（不计排序） | 排序 + 固定 1 个 + 双指针 |
| 18 四数之和 | $O(n^3)$ | $O(1)$（不计排序） | 排序 + 固定 2 个 + 双指针 |
| 167 两数之和 II | $O(n)$ | $O(1)$ | 对撞双指针（利用有序） |

## 八、和"滑动窗口"的区别

| | 双指针（对撞） | 滑动窗口 |
|---|---|---|
| 指针方向 | 相向而行 | 同向（都往右） |
| 典型问题 | 有序数组求和、最大面积 | 连续子串/子数组的最长最短 |

## 九、面试可以这么说

> "双指针的**正确性来自单调性**：能证明'移动某个指针一定不会丢掉最优解'，才能这么做。
> 15/18 是'排序 + 固定若干项降维成两数之和'，难点不在双指针而在**去重**——外层用 `nums[i] == nums[i-1]` 跳过，内层在找到解后用 while 跳过相邻重复。"
