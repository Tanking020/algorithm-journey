# 滑动窗口 · 章节笔记

> 对应题目：209 长度最小的子数组 · 3 无重复字符的最长子串 · 438 找到字符串中所有字母异位词 · 567 字符串的排列 · 76 最小覆盖子串
>
> 更新时间：2026-09-30

---

## 一、核心思想

**两个同向指针圈出一个窗口，窗口随 `right` 扩张、随 `left` 收缩；用 O(1) 的方式维护窗口状态，让"判断是否满足条件"不用重新扫描。**

**关键前提（决定能不能用滑动窗口）**：窗口"扩张/收缩"后，判定条件要有**单调性** —— 比如
- 209：全为正数，窗口和只增不减 → 可以用
- 560：有负数，窗口和不是单调的 → 只能用前缀和，**不能用滑动窗口**

> 这一点是滑动窗口最容易被忽略的前提，面试常被追问。

## 二、识别信号

| 看到题面出现 | 该想到 |
|---|---|
| "**连续**子数组 / 子串" + "最长 / 最短 / 是否包含" | 滑动窗口 |
| "每个字符出现次数"、"异位词"、"排列" | 滑动窗口 + **计数** |
| "窗口是定长"（如 438/567 找 p 的异位词，长度固定） | **定长窗口** |
| 要求 $O(n)$，数组元素非负 | 滑动窗口（前缀和也可，但窗口更简洁） |

## 三、两个模板

**A. 变长窗口（求最长 / 最短）**
```python
left = 0
for right in range(n):
    扩张：把 s[right] 纳入窗口状态
    while 不满足条件:                # 求"最长"时，收缩到重新满足
    收缩：撤销 s[left]，left += 1
    更新答案
```

**B. 定长窗口（438 / 567，窗口长度固定为 len(p)）**
```python
for right in range(n):
    扩张
    while right - left + 1 > len(p):     # 超长就收缩，保证窗口恒为 len(p)
        收缩
        left += 1
    if formed == required: ...
```

## 四、⭐ `formed` 满足变量法（76 / 438 / 567 通用，本章最重要的收获）

不用"两个字典比较"，而是维护一个整数 `formed` = **已经满足计数的字符种类数**。

```python
need = Counter(t)
required = len(need)        # ⚠️ 去重后的【字符种类数】，绝不能写 len(t)！
window = defaultdict(int)
formed = 0

for right in range(n):
    window[s[right]] += 1
    # 扩张后：从"不够"变成"刚好够"才 +1
    if s[right] in need and window[s[right]] == need[s[right]]:
        formed += 1

    while 需要收缩的条件:
        # 收缩前：用即将被移除的 s[left] 判断"是否从满足变回不满足"
        if s[left] in need and window[s[left]] == need[s[left]]:
            formed -= 1
        window[s[left]] -= 1
        left += 1

    if formed == required:      # 覆盖了全部目标字符
        ...
```

**三个"必须"**：

1. **必须做存在性判断 `ch in need`**（否则 `formed` 虚高）；
2. **必须在"刚好够"时 +1 / "刚好不够"时 -1**（用 `==` 判断，而不是 `>=`）；
3. **`required` 必须是 `len(need)`**（种类数）。

## 五、我踩过的坑（本章坑最多，重点回顾）

### 🔴 坑 1：变量定义了却不更新 → 死循环（犯过两次：567、438）

```python
# ❌ 错误写法
window_length = right - left + 1
while window_length > len(s1):     # window_length 是"快照"，循环里 left 变了它不变 → 死循环！
    left += 1

# ✅ 写法一：直接用表达式实时计算
while right - left + 1 > len(s1):

# ✅ 写法二：在循环内同步更新变量
while window_length > len(s1):
    left += 1
    window_length -= 1
```

> **通用教训**：凡是"先算出变量、再拿变量当 while 条件"的写法，都要检查**循环体内有没有更新它**。
> 这个坑在 20 题（`b1/b2/b3`）也犯过 —— **同一类错误出现了三次，务必记住。**

### 🔴 坑 2：`required` 用错

`required = len(need)`（字符**种类**数）✅ ｜ `len(s1)`（含重复的总长度）❌

### 🔴 坑 3：438 不能用"两个字典直接比较"

```python
# ❌ window_dict == need_dict 不行
#    因为 defaultdict 访问过的键会留下 0 值（如 {'a':0, 'b':1, ...}），导致误判
# ❌ 用 Counter 再过滤 0 值 → 每次比较 O(字符集)，时间复杂度上去了
# ✅ 正解：用 formed，或者用长度 26 的计数数组
```

> 这就是 438 和 567 要引入 `formed` 的原因。

### 🔴 坑 4：209 不能用切片求和

```python
# ❌ cur_sum = sum(nums[left:right+1])    ← 切片本身 O(n)，整体退化成 O(n^2)
# ✅ cur_sum += nums[right]（扩张时同步累加）
```

### 🟡 坑 5：更新答案的**时机**

| 题 | 更新时机 | 原因 |
|---|---|---|
| 76 最小覆盖 | 在 `while formed == required` **内部**、收缩**之前** | 循环内始终满足条件，收缩后就不满足了 |
| 209 最短子数组 | 在 `while cur_sum >= target` **内部**、收缩**之前** | 同上 |
| 3 最长无重复 | 放在 while **外面**（窗口稳定时） | 收缩期间窗口正在失效 |
| 438/567 | 收缩**之后**（窗口长度已等于 len(p)） | 长度对了才有意义 |

**一句话**：**"当前窗口满足条件"的那一刻，才是更新答案的时候。**

## 六、必记语法点

| 知识点 | 说明 |
|---|---|
| `Counter(t)` | 一次性 $O(n)$ 统计，返回 `{'字符': 次数}` |
| `defaultdict(int)` | 访问不存在的键自动建 0；省掉 `if key not in d`；但**会残留 0 键** |
| `float('inf')` | 求最小值时当初始值（209），最后要 `return 0 if ... == inf` |
| 字符集固定时 | 用长度 26 的数组替代 dict，**速度明显更快**（力扣实测感受） |

## 七、复杂度速查

| 题 | 时间 | 空间 | 窗口类型 |
|---|---|---|---|
| 3 无重复字符的最长子串 | $O(n)$ | $O(m)$（字符集） | 变长，求最长 |
| 76 最小覆盖子串 | $O(n+m)$ | $O(m)$ | 变长，求最短 |
| 209 长度最小的子数组 | $O(n)$ | $O(1)$ | 变长，求最短 |
| 438 找到所有字母异位词 | $O(n)$ | $O(m)$ | **定长** |
| 567 字符串的排列 | $O(n)$ | $O(m)$ | **定长** |

**为什么是 $O(n)$**：每个元素最多被 `left`、`right` 各访问一次 → **均摊 $O(1)$ / 元素**。

## 八、面试可以这么说

> "滑动窗口的**前提是判定条件随窗口单调**——像 209 全是正数才行；如果数组有负数（比如 560），窗口和不再单调，就得换成前缀和 + 哈希表。
> 实现上我用 `formed` 维护'已满足的字符种类数'，避免每次比较整个字典；更新答案的时机很关键：要放在'窗口仍然满足条件'的那一刻。"

## 九、做题时的自查清单

- [ ] 窗口是**定长**还是**变长**？
- [ ] `while` 条件是"**满足**时收缩"还是"**不满足**时收缩"？（76 是前者，209 是后者）
- [ ] `while` 里的条件变量**有没有在循环内更新**？（⚠️ 死循环重灾区）
- [ ] 答案在**收缩前**还是**收缩后**更新？
- [ ] 计数类题目：有 `formed` 吗？`required` 是**种类数**吗？有做**存在性判断**吗？
