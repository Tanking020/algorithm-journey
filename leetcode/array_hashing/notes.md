# 数组 & 哈希表 · 章节笔记

> 对应题目：1 两数之和 · 49 字母异位词分组 · 128 最长连续序列 · 242 有效的字母异位词 · 349 两个数组的交集 · 560 和为 K 的子数组
>
> 更新时间：2026-09-30

---

## 一、核心思想

**哈希表 = 空间换时间。** 把"线性查找 O(n)"变成"哈希查找 O(1)"，从而消掉一层循环。

一句话模板：**把"要我找两个元素"变成"一边遍历、一边查历史"。**

## 二、识别信号

| 看到题面出现 | 该想到 |
|---|---|
| "是否存在"、"出现过没有"、"有没有配对" | **set / dict 查询** |
| "两数之和"、"找差值"、"互补" | **哈希表存历史**（1） |
| "统计次数"、"是否由相同字符组成" | **Counter 计数**（242） |
| "去重"、"交集"、"唯一" | **set**（349） |
| "连续子数组的和" | **前缀和 + 哈希表**（560） |
| "最长连续序列"（值连续，不是位置连续） | **set + 只从起点出发**（128） |

## 三、五个可复用套路

**① 一次遍历 + 查历史**（1 两数之和）
```python
seen = {}
for i, num in enumerate(nums):
    if target - num in seen:
        return [seen[target - num], i]
    seen[num] = i          # 先查后存，天然避免"自己配自己"
```

**② 计数比较**（242 有效的字母异位词）
```python
if len(s) != len(t):       # 长度不等 → 提前剪枝
    return False
return Counter(s) == Counter(t)
```

**③ 用"可哈希的键"做分组**（49 字母异位词分组）
```python
groups = {}
for w in strs:
    key = tuple(sorted(w))     # list 不可哈希 → 必须转 tuple
    groups.setdefault(key, []).append(w)
return list(groups.values())
```

**④ 集合化后只从"起点"出发**（128 最长连续序列）
```python
num_set = set(nums)
for num in num_set:
    if num - 1 not in num_set:      # 关键：只从序列起点开始数
        ...                          # 否则会退化成 O(n^2)
```

**⑤ 前缀和 + 哈希表**（560 和为 K 的子数组）
```python
prefix_count = {0: 1}               # 关键初始化：空前缀和出现 1 次
prefix = 0
for num in nums:
    prefix += num
    count += prefix_count.get(prefix - k, 0)    # 找"历史上差 k 的那个前缀和"
    prefix_count[prefix] = prefix_count.get(prefix, 0) + 1
```

> **前缀和的本质**：把"子数组求和"变成"两个累计和相减"。所以 560 里的判定式是
> `prefix_sum_当前 - prefix_sum_历史 = k`。

## 四、我踩过的坑（重点回顾）

| 题目 | 踩的坑 | 教训 |
|---|---|---|
| **49** | 第一版只把异位词"聚拢"了，没分组装成列表 | **先想清楚输出结构**再写代码 |
| **128** | `max_length` 的更新想放到 if 外面 | 只有算出了 `current_length` 才谈得上更新 |
| **242** | ① 用 `sorted` → $O(n\log n)$ 不达标；② 用 `s.count()` 循环 → 其实是 $O(n^2)$ | ⚠️ **力扣的毫秒数受测试数据影响，不能作为算法优劣的判据**——看复杂度，别信跑分 |
| **560** | 第一版用 `sum > k` 提前终止 → **完全错误** | ⚠️ **有负数时累加不单调**，不能"超过就停"。改用**等于**判定 |
| **560** | `prefix_count[prefix] += 1` 会 KeyError | 用 `.get(prefix, 0) + 1`，或 `defaultdict(int)` |

> 560 这个坑最典型：**"看起来更快"的剪枝依赖了题目没给的假设（非负）**。

## 五、必记语法点

| 知识点 | 说明 |
|---|---|
| `list` 不可哈希 | **不能**做 `dict` 的键；`tuple` / `str` / `int` 可以 |
| `set.add(x)` | 集合无序，**没有 `append`**，也没有"末尾"概念 |
| `Counter(s)` | `dict` 的子类，$O(n)$ 计数；`Counter(s) == Counter(t)` 直接比较 |
| `d.get(k, default)` | 安全取值，**不会写入字典**（`setdefault` / `defaultdict` 会） |
| `defaultdict(int)` | 访问不存在的键自动建并给 0，省掉 `if key not in d` |
| `dict.values()` | 取出所有值（49 里用来交出分组结果） |

## 六、复杂度速查

| 题 | 时间 | 空间 | 关键手法 |
|---|---|---|---|
| 1 两数之和 | $O(n)$ | $O(n)$ | 哈希查历史 |
| 49 字母异位词分组 | $O(n \cdot k\log k)$ | $O(n \cdot k)$ | 排序后作键 |
| 128 最长连续序列 | $O(n)$ | $O(n)$ | set + 只从起点数 |
| 242 有效的字母异位词 | $O(n)$ | $O(k)$ | Counter 比较 |
| 349 两个数组的交集 | $O(n+m)$ | $O(n+m)$ | set 查询 + 去重 |
| 560 和为 K 的子数组 | $O(n)$ | $O(n)$ | 前缀和 + 哈希表 |

## 七、面试可以这么说

> "这一类的核心是**用哈希表把一层的线性查找压成 O(1)**。
> 1、242 是查'出现过没有'；560 稍微进阶一点，需要**前缀和**把'子数组求和'转成'两个前缀和相减'，再用哈希表查历史。
> 特别要注意 560 里**数组可能含负数**，所以不能做'超过就停'的剪枝。"
